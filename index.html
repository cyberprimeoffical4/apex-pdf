WHAT'S INSIDE

Everything a PDF app should do, in four groups.

No ribbon menus, no hunting for buried settings — each tool lives where you'd expect it, and every annotation you place is instantly resizable.

✎

Draw & annotate

Nine tools, all with live size handles.

  • Pen, highlighter, lines, arrows, shapes, callouts, and text
  • Color, stroke width / font size, opacity, dashed strokes
  • Click to select, drag corners to resize, drag body to move
  • Undo / redo, duplicate, per-page clear
⤢

Navigate & view

Scrolls like a real viewer, not a slideshow.

  • Mouse-wheel scroll flows across page boundaries
  • Shift+scroll to pan, Ctrl+scroll to zoom at cursor
  • Fit Width, Fit Page, Actual Size
  • Find in document · Spotlight-style Command Palette
▤

Organize pages

Restructure a document without leaving the app.

  • Merge, split, and extract page ranges
  • Rotate, duplicate, delete, insert, reorder pages
  • Annotations remap automatically when pages move
  • Editable document properties (title, author, keywords)
⇄

Convert & protect

The utility tools you reach for last, built in.

  • Images → PDF, and PDF pages → images
  • Add or remove passwords / encryption
  • Diagonal watermarking
  • Register as a Windows "Open with" PDF app in one click

GET IT RUNNING

Three lines, and you're editing PDFs.

It's one file. Clone it, install two dependencies, run it.

$ git clone https://github.com/cyberprimeoffical4/apex-pdf.git
$ cd apex-pdf
$ pip install PyMuPDF Pillow --break-system-packages
$ python3 "ApEx PdF.py"
Requires Python 3.9+ Depends on PyMuPDF, Pillow, Tkinter Runs on Windows · macOS · Linux
